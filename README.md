# Carruseles Punilla Digital

Skill básica de ejemplo creada por Punilla Digital para escribir guiones de carruseles comerciales.

## Alcance
Tabla por placa con título, descripción y visual; post de Instagram. Esta versión prepara contenido e instrucciones; no incluye scripts, integraciones ni exportación automática de archivos.

## Uso
- Consultar [SKILL.md](SKILL.md) y proporcionar los datos de entrada que indica.
- En un agente compatible, colocar la carpeta `carruseles-punilla-digital` con el archivo `SKILL.md` en el directorio de skills que admita ese entorno.
- En otros asistentes, adjuntar o pegar las instrucciones como contexto. Esto no garantiza instalación ni activación automática.

## Personalizar la marca
Cambiar la sección «Identidad configurable» en SKILL.md o indicar la configuración en cada pedido:

```text
Marca: Mi negocio
Logo: archivo adjunto
Colores: #7C3AED, #F97316 y #FFFFFF
Tipografía: sans serif o la fuente de mi marca
Tema: claro u oscuro
Tono: profesional y directo
```

La paleta incluida es ilustrativa. No se incluye un archivo de logo; utilizar uno propio. La identidad afecta la presentación cuando corresponde, sin cambiar datos o cálculos.

> Prepará un carrusel de cinco placas sobre páginas web, tema oscuro y gráficos 3D.
